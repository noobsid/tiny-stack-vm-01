# tiny-stack-vm — an exact tiny stack VM

Entry for the [tiny-stack-vm-01](https://make.fun/bounty/tiny-stack-vm-01-run-20261122)
bounty on make.fun. `main.ts` interprets the ISA exactly as the reference
VM: wrapping arithmetic, unsigned DIVU/MODU/LTU, all ten traps in order,
step and output limits. Byte-exact on the practice set and 880 fuzz cases.
